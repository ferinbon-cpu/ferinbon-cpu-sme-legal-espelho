# SME Legal — Espelho

Infraestrutura auxiliar e auditável para coletar arquivos públicos do site SME Legal e transferi-los ao Google Drive SME_LIMEIRA.

## Regras
- zero custo;
- não usar TinyFish pago;
- preservar bytes originais;
- GitHub é apenas ponte de coleta/QA; o acervo canônico fica no Drive SME;
- cada lote deve registrar URL, nome, tamanho, MIME e SHA-256.
